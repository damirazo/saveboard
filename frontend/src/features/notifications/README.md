# Уведомления

`NotificationBell` отображается при реальной сессии, счётчик под иконкой обновляется каждые 15 секунд и после прочтения. Ошибка счётчика показана тире, а не ложным нулём.

`/notifications` — защищённая страница: десять заголовков на страницу, жирный шрифт и кобальтовая точка для непрочитанных. При выборе сообщения открывается соседняя панель с подробностями, на телефоне она размещается над списком; только успешная загрузка вызывает POST read. Ошибка прочтения сохраняет непрочитанный статус и позволяет повторить запрос. Текст не интерпретируется как HTML. Ключи TanStack Query содержат session_id, общий механизм выхода очищает кэш.

Ссылка в уведомлении открывает `/posts/$postId`; сервер повторно проверяет доступ к посту. Публичный пост доступен гостю, приватный — владельцу. Политика доступа к уведомлениям проверяется сервером, не фильтрацией браузера.

Проверка: `pnpm exec playwright test notifications.spec.ts` из frontend.
