# Общие компоненты Saveboard

Страницы в `features/` собирают интерфейс из компонентов, передают данные и обработчики. Повторяющуюся разметку не копируем в страницы. Общие экспорты доступны из `components/index.ts`; прямой импорт из файла компонента также допустим.

## Где менять оформление

- `src/styles/tokens.css` — общая палитра, цвет фокуса, границы и скругление контролов, скругление карточек, тени.
- `src/styles/components.css` — единая реализация оформления и адаптивности всех блоков. Поля и кнопки оформляются собственными классами, без зависимости от страницы входа или библиотеки.
- `src/styles.css` — только импорты и базовые стили документа.
- Файл конкретного компонента — структура и общее поведение. Изменение автоматически применяется во всех местах использования.

Не переопределяйте общий компонент копией его CSS на отдельной странице. Для устойчивого нового варианта добавляйте именованный вариант в компонент; для контента используйте параметры и слоты.

## Состав

- `layout/app-shell.tsx`: оболочка, главный контент; `header` и `footer` заменяемы, `footer={null}` убирает панель шаблонов.
- `layout/sidebar.tsx`: единые меню и профиль для `Viewer`, раскрытие на мобильном экране. Представление пользователя не заменяет проверку прав на сервере.
- `layout/app-header.tsx`: верхняя панель с `title`/`actions`, отдельная навигация по шаблонам.
- `layout/auth-layout.tsx`: композиция страницы авторизации и `FormCard` с произвольным содержимым и футером.
- `navigation/breadcrumbs.tsx`: массив подписей; для промежуточного элемента можно передать `link` с React Router Link. Последний элемент помечается `aria-current`.
- `navigation/pagination.tsx`: управляемые `page`, `pageSize`, `total`, обработчики изменения страницы/размера. Нумерация с 1; по умолчанию размеры 10/20/50. Длинная выдача сокращается многоточиями; при нулевой выдаче переходы отключены.
- `content/page-heading.tsx`: заголовок, счётчик, описание, действия; отдельно `EmptyState`.
- `content/search-panel.tsx`: строка поиска с управляемым значением, подписью и подсказкой.
- `content/filter-panel.tsx`: группы фильтров, произвольное содержимое панели и необязательная сортировка.
- `content/post-card.tsx`: типизированный `PostCard` для web/text/file, `TagList`, `LinkPreview`, `FilePreview`. Все подписи, вложения и цитаты берутся из объекта поста; отсутствующие блоки не рисуются. Действия скрыты, если соответствующий обработчик не передан. `actions` позволяет дополнить карточку.
- `ui/button.tsx`: кнопки default/outline/icon/filter/tag, `asChild` для ссылки с тем же оформлением. По умолчанию `type="button"`, для отправки формы задайте `type="submit"`.
- `ui/form-field.tsx`: `Input`, `FormField` с подписью, подсказкой, ошибкой и `password` для показа пароля; `Select`; `FormMessage` для результата/ошибки. Идентификаторы поля создаются автоматически, если `id` не передан.
- `ui/divider.tsx`: разделитель с подписью.
- `auth/oauth-placeholder.tsx`: общая отключённая OAuth-кнопка с настраиваемой подписью.

## Подключение на другой странице

```tsx
import { SearchPanel, FilterPanel, FilterGroup, PostCard, Pagination } from '../../components';

<SearchPanel value={query} onChange={changeQuery} label="Поиск документов" />
<FilterPanel sort={{ value: sort, options: sortOptions, onChange: changeSort }}>
  <FilterGroup label="Тип" value={kind} options={kinds} onChange={changeKind} />
</FilterPanel>
{pagePosts.map(post => <PostCard key={post.id} post={post} onTagClick={changeQuery} />)}
<Pagination page={page} pageSize={pageSize} total={total}
  onPageChange={setPage} onPageSizeChange={changePageSize} />
```

Компоненты не выполняют запросы и не владеют коллекцией данных. На странице библиотеки поиск и фильтрация выполняются до разбиения на страницы, изменение условий/размера сбрасывает страницу. Для серверной пагинации передавайте уже загруженные записи и общий `total` из API, повторно не применяя `slice`. `demo-posts.ts` — отдельный источник демонстрационных данных, не часть компонентов.

Валидация и запросы авторизации остаются в feature-слое. OAuth и формы на текущих маршрутах сохраняют режим заглушек. Проверки компонентов покрывают границы/пустую/большую пагинацию и отсутствие выдуманного содержимого постов; браузерные тесты — комбинации поиска, сортировки, фильтров и страниц, формы, гостя, пользователя и мобильную компоновку.
