# Вопросы и расхождения

Обновлено: 2026-10-09. Эти записи не блокируют независимые задачи. Поднимай вопрос, когда он влияет на конкретное изменение; после ответа фиксируй дату, источник решения и ссылку на обновлённый документ.

## Q1 — notes и posts

Факт: foundation notes использует теги владельца; новая модель posts — глобальный справочник тегов. Основание: [posts README](../../backend/internal/posts/README.md), миграции `00001_foundation.sql` и `00004_posts.sql`.

Не определено: заменяет ли posts прежнюю модель или обе имеют самостоятельное назначение; как переносить данные и сопоставлять frontend-типы web/text/file с note/link/photo. Уточнить перед проектированием продуктового API или миграцией данных. До решения сохранять обе модели.

## Q2 — свежесть документации auth и окружения

`docs/development.md` всё ещё говорит об отсутствии Git и интерфейса входа; backend identity README — об отсутствии frontend-хранения refresh. В рабочем дереве уже есть `.git`, login и sessionStorage ([frontend auth](../../frontend/src/features/auth/README.md)).

При обновлении этих документов сверить код и результаты релевантных тестов; не переносить устаревшие утверждения в новые требования. Это задача синхронизации документации, а не повод откатывать существующий код.

## Q3 — полнота веб-архивов

2026-10-13 пользователь выбрал статический финальный DOM после выполнения скриптов при захвате, без JS replay при просмотре; обработка фоновая. Решение и проверенные границы — [ADR-0002](../decisions/0002-static-link-captures.md). Обещание интерактивного зеркала не применяется. Общая матрица поддерживаемых сайтов и оставшиеся ограничения P0.2 не закрываются одним успешным smoke.
