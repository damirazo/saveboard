# Разработка с Codex

Входная точка — [AGENTS.md](../../AGENTS.md). В нём собраны общие инструкции и порядок чтения контекста. Для backend и frontend есть локальные инструкции. Остальные Markdown-файлы читаются по ссылкам и условиям из инструкций; они не являются самостоятельной автоматической памятью.

## Где что хранить

- [context.md](context.md): краткий актуальный снимок, границы реализации, ссылки на текущую работу. Обновляется при значимых изменениях.
- [questions.md](questions.md): существенные неопределённости, расхождения документов и кода, условия уточнения. Ответ переносится в соответствующую спецификацию или ADR.
- [PLANS.md](../../PLANS.md) и [шаблон задачи](tasks/TEMPLATE.md): план, приемка, проверки и передача продолжительной работы.
- [Решения](../decisions/README.md): почему выбран подход и чем его заменили, если решение изменилось.
- [Архитектура](../architecture.md), [roadmap](../implementation-plan.md), [разработка](../development.md): предметная спецификация, этапы и запуск окружения. Не копировать их целиком в агентские файлы.

## Практика

Новую задачу можно начать так: «Реализуй … Критерии приемки: … Учти AGENTS.md и текущий контекст». Codex сопоставляет контекст с рабочим деревом, выбирает проверки и при необходимости создаёт файл плана.

Для продолжения: «Продолжи задачу по docs/agent/tasks/<имя>.md; проверь фактическое состояние и выполни следующий шаг». Перед сменой чата: «Обнови план задачи и контекст для продолжения в новом чате».

Не требуется обновлять все файлы после каждого ответа. Сохраняй только сведения, полезные следующей сессии: решения, ограничения, проверенный прогресс и следующий шаг. Не сохраняй стенограммы и секреты. Держи завершённые подробности в планах задач и Git, а контекст коротким.

При одновременной работе в разных чатах используй отдельные планы и согласованные области изменений; общий context обновляй с учётом чужих правок. Эти файлы сами по себе не запускают агентов, автоматизации, коммиты или деплой.

Формат инструкций опирается на [официальное руководство AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md). Подход к длительным задачам адаптирован из [рекомендаций OpenAI по планам](https://developers.openai.com/cookbook/articles/codex_exec_plans); структура плана здесь — соглашение Saveboard.
