# Фоновая RAG-индексация ссылок

Статус: done. Дата: 2026-10-14.

## Приёмка

Независимый выключенный по умолчанию флаг link-поста запускает долговечную River-задачу: рендер через существующую SSRF-границу, Readability, нормализованный текст, ограниченные chunks, закреплённые BGE-M3 эмбеддинги Ollama, Qdrant. Успех и окончательная ошибка уведомляют владельца ровно один раз. CRUD не зависит от доступности индекса. Повторы, срок, восстановление, ограничение конкуренции; устаревшие поколения не публикуются и очищаются после смены URL/типа, выключения или draft.

## Исходные факты / решения

Readability уже установлен, search содержит только клиент-заготовку. BGE-M3 lock: 1024 dimensions, качество RU/EN ещё не оценено. Qdrant — производный индекс; canonical text и active generation в PostgreSQL. Поисковый/RAG-chat endpoint в эту задачу не входит. Сохраняем предшествующие незакоммиченные auth/capture/notifications изменения. В текущем одном worker RAG и capture делят один слот браузерной очереди, задачи разные.

## Передача / ограничения

Готово локально, блокеров нет. Следующий шаг для этой задачи не требуется; поиск/RAG-chat остаются отдельной будущей функциональностью. Очистка текста эвристическая, индекс ограничен 100000 code points на документ; качество retrieval RU/EN не оценивалось. Qdrant не источник ACL: будущая выдача должна проверять PostgreSQL current generation и права. После удаления текста остаются компактные tombstones для повторной сверки внешнего индекса; политика архивирования tombstones не реализована. Общий rescue повышен до 6 минут для RAG-попытки 5 минут. Не выполнялись commit/push; предыдущие незакоммиченные изменения сохранены.
