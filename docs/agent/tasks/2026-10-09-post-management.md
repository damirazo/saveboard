# Создание и управление постами

Статус: done
Создано: 2026-10-09

## Результат и приемка

- Активный авторизованный пользователь создаёт пост; только автор меняет его и переводит в draft при удалении.
- Обязательны название, тип и хотя бы один тег; autocomplete по префиксу, создание с транслитерацией, удаление выбранных тегов.
- Заметки: визуальный/исходный Markdown, безопасный рендер и серверная проверка.
- Фото: drag/drop, максимум 32, проверка содержимого, сетка до 5 колонок/3 строк и полноэкранный просмотр.
- Ленты используют API, скрывают draft и чужие приватные посты.

## Решения

Используется существующая модель posts; legacy notes не меняется. Тип link сохраняется с HTTP(S) URL. Приватность по умолчанию private, пользователь может выбрать public. Персональная лента — собственные опубликованные посты. Friends/unlisted не включаются в новую форму до реализации соответствующих сценариев.
