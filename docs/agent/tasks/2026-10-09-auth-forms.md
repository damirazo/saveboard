# Вход и регистрация через формы

Статус: done
Создано: 2026-10-09

## Приемка

- Регистрация по username/email/password создаёт активного пользователя и сессию, переводит в личную ленту.
- Пароль хешируется; аккаунт и сессия создаются атомарно. Email остаётся непроверенным; подтверждение адреса и OAuth UI вне объёма.
- Вход по username/email, понятные ошибки, предотвращение повторной отправки, подтверждение пароля на форме.
- Уникальность username/email без учёта регистра, серверная и клиентская валидация; ошибки не сохраняют ложную сессию.
- Проверены API с PostgreSQL и браузерные формы. Локальная версия на 8080 обновлена после проверок.
