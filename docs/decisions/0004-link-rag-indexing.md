# ADR-0004: Независимая индексация текста ссылок

Статус: accepted. Дата: 2026-10-14. Основание: запрос пользователя; технические детали делегированы в рамках реализации.

## Решение

Добавить независимый `index_rag=false` для link, отдельную River-задачу `post.rag` и уведомления. Использовать установленный Readability после рендера существующим изолированным Chromium, без повторного выполнения скриптов в jsdom. PostgreSQL хранит canonical text и активную генерацию; Qdrant — производные векторы с текстом chunks в payload. BGE-M3 локально в Ollama, имя/digest из существующего lock, Cosine/1024. До окончания всех upsert документ не ready.

Повторное выполнение пишет те же UUID точек. Смена URL/типа, выключение и draft исключают active generation в той же транзакции, очистка Qdrant выполняется отдельно с устойчивым tombstone. Серверный поиск в будущем обязан перепроверять актуальность и ACL PostgreSQL до возврата текста — один owner_id в payload недостаточен.

## Последствия

Индексация и capture независимы логически, но делят один браузерный слот. Таймаут RAG — 5 минут, срок всей задачи — 30 минут, три попытки. Общий порог River rescue повышен с 3 до 6 минут, дополняя ADR-0003; таймаут capture остаётся 2 минуты. Сервисные сбои не блокируют CRUD. Tombstones остаются после очистки для повторной сверки неоднозначных внешних записей; отдельная политика их архивирования пока не добавлена. В этом изменении нет RAG-чата, semantic search API и оценки качества retrieval. Полные параметры и проверки — [search README](../../backend/internal/search/README.md).
